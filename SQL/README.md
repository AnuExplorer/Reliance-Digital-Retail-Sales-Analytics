# Data Profiling

## Purpose
This section documents the data quality investigation performed on the raw retail sales data using MySQL.

## Issues Investigated
- Missing and NULL values
- Duplicate records and duplicate groups
- Inconsistent customer and product attributes
- Invalid or inconsistent dates
- Delivery-duration discrepancies
- Inconsistent product specifications and units

## Profiling Approach
SQL queries are used to inspect column values, identify anomalies, compare distinct values, and quantify data quality issues before applying cleaning rules.
